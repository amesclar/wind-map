# Release Notes - v0.13.1

A one-fix release: the keyless OpenStreetMap base layers load again.

---

## Fixes

- **OpenStreetMap tiles were blocked (SCRUM-288):** 0.13.0 sent `Referrer-Policy: same-origin`,
  which makes the browser drop the `Referer` from every cross-origin request. The OpenStreetMap
  tile usage policy requires a `Referer` from web pages and forbids a restrictive policy outright, so
  its volunteer servers answered the default `osm_dark` base — and `osm_standard` — with the
  "Access blocked: app is not following the tile usage policy" image. The header is now
  `strict-origin-when-cross-origin`, which the policy allows and which still sends only the origin,
  never the path, to other hosts. A test pins the value and a comment next to it records why it must
  not be tightened again.

---

**Upgrade notes:** no schema, data or dependency change, and no configuration to update. Nothing else
in 0.13.0 is affected: the CARTO, NOAA chart and Seamap bases never depended on this header.
