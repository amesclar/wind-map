# Release Notes - v0.5.0

Release v0.5.0 adds the wind speed color gradient to the map — a smooth color field under the
barbs, with an on-map legend in your chosen speed unit — plus an in-app weather model guide and
a round of CI and AI-governance automation.

---

## What's New

### Wind speed color gradient (SCRUM-121, SCRUM-122, SCRUM-123, SCRUM-124, SCRUM-143, SCRUM-144)
- **Gradient overlay:** a smooth wind speed color field drawn beneath the barbs, toggled separately from them in Map Settings (off by default, remembered across reloads).
- **Shared grid fetch:** the gradient and the barbs read the same `/api/weather/grid` response, so turning the gradient on adds no requests — one fetch per pan or zoom, for every layer.
- **Readable base map:** the overlay is drawn at 55% opacity, so coastlines, roads and labels stay visible through the colors, and every barb gains a dark halo so its temperature color stays legible on any gradient color.
- **Locked to the viewport:** panning, zooming and window resizes repaint the field over the visible area instead of leaving a stale or shifted frame.
- **On-map legend:** a full-width strip above the forecast drawer shows the same gradient with tick labels in knots, km/h, mph or m/s (5 kt / 10 km/h / 5 mph / 5 m/s steps), drops every second label on narrow screens, and rides just above the drawer when its forecast panel expands.

### Weather model guide (SCRUM-110)
- In-app guide describing each available Open-Meteo model, its resolution and how often it updates, so the model picker explains itself.

## Quality & Governance
- **Jira automation (SCRUM-141):** tickets move to Done as soon as a PR's required checks pass, and the merge commit hash is recorded on the ticket.
- **Container rebuild rule (SCRUM-132, SCRUM-140):** every merge and version bump rebuilds and restarts the local container, and the Kiro hook uses the shared script with a relative path.
- **AI rule parity (SCRUM-139):** Freebuff's rules are generated from the same steering files as the other tools, including a workflow inventory.
- **Docs cleanup (SCRUM-131):** obsolete SCRUM-92 and SCRUM-95 markdown removed.

## Internal
- **Barb drawing API (SCRUM-93):** `generateWindBarbSvg` takes an options object, and the TypeScript configs are split for app, test and node code.

## Compatibility
- No API or database changes: existing saved locations, caches and settings carry over unchanged.
