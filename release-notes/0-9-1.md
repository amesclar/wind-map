# Release Notes - v0.9.1

Release v0.9.1 is a patch release for the Map Settings dialog. On shorter windows the dialog was
taller than the viewport, so the **Done** button sat below the fold with no way to scroll to it. The
dialog now caps itself to the screen, scrolls only its body, and lays its options out in two columns.

---

## Fixes

### The Map Settings dialog fits the screen and keeps Done in view (SCRUM-183)
- **Root cause:** the panel had no height cap and its content had no scroll area. With the base-map
  choices, the CARTO key and three layer toggles, the dialog grew past the viewport and pushed the
  footer — the only way to close it besides the X — off screen.
- **Always reachable:** the panel is capped at the viewport (`max-h-full`), only the body scrolls
  (`overflow-y-auto`, `flex-1 min-h-0`) and the footer is `shrink-0`. Done stays visible however tall
  the content gets, matching the Preferences dialog.
- **Two columns from `md` up:**
  - left — base map style, the CARTO API key and **Save Key**;
  - right — Wind Grid Overlay, Wind Color Gradient and Water Currents.
- Below the breakpoint the groups stack in that order with a divider between them, and the dialog
  keeps a comfortable width (`max-w-2xl`) on desktop.

## Compatibility
- **Behaviour:** no change. Every toggle, the tile-layer radios, the key save/clear flow and the X
  button work as before; only the arrangement and scrolling changed.
- **API and data:** unchanged. No endpoints, schema, settings keys or stored preferences are touched.
- **Dependencies:** none added or upgraded.
