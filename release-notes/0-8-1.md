# Release Notes - v0.8.1

Release v0.8.1 is a patch release for the wind colour legend. With the gradient on, the legend
strip was present but painted underneath Leaflet's map panes, so it was invisible. It now sits above
the map content and below the map controls, and the exported legend is unchanged.

---

## Fixes

### Wind colour legend visible again (SCRUM-168)
- **Cause:** the legend was absolutely positioned at `z-index: 30` inside the map's isolated stacking context, while Leaflet's content panes use much higher levels — tiles 200, the wind colour pane 250, overlays 400, markers 600 and pop-ups 700. The gradient therefore covered the strip.
- **Fix:** the legend now renders at a shared `LEGEND_Z_INDEX` of 750, above all map content and pop-ups, and below Leaflet's controls (800/1000), so the zoom buttons and attribution keep priority. The change is covered by a regression test that guards that ordering.
- The legend keeps `pointer-events: none`, its 24 px offset above the attribution, all tick labels (every second label dropped below 640 px) and the selected speed unit. The exported legend and its shared scale are unaffected.

## Compatibility
- No API, data or dependency changes. Saved locations, preferences, units and forecast caches are untouched.
- The change is CSS/stacking only; map interaction, barb selection and pop-ups behave exactly as in v0.8.0.
