# Release Notes - v0.6.0

Release v0.6.0 is the dependency round from the nine dependabot branches (SCRUM-146): every direct
dependency is now pinned exactly, the frontend moved to Vite 8, ESLint 10 and Tailwind CSS 4, and the
app is built and tested on Node 24 and Python 3.14. There are no user-facing behaviour changes.

---

## What's New

### Toolchain and runtimes (SCRUM-149, SCRUM-150)
- **Vite 8** with `@vitejs/plugin-react` 6 and Vitest 5.1.1 (with its v8 coverage provider). The Vite and Vitest configs import local modules with explicit `.ts` extensions, because Vite's native config loader cannot resolve extensionless imports.
- **Node 24 LTS and Python 3.14 everywhere:** `node:24-alpine` builds the frontend, `python:3.14-alpine` runs the backend, CI uses the same two versions, `engines.node` is `>=24.0.0`, `@types/node` follows the runtime, and `ruff` targets `py314`.
- **Pinned requirements:** `requirements.txt` and `requirements-dev.txt` were regenerated with `pip-compile` on Python 3.14, so the resolution matches the image.
- **Smaller image:** the runtime image dropped from 148 MB to 145 MB.

### Tailwind CSS 4.3 (SCRUM-151)
- **CSS-first configuration:** the `dark` palette moved into an `@theme` block in `frontend/src/index.css`, class-based dark mode became an `@custom-variant`, and `tailwind.config.js` is gone.
- **New PostCSS plugin:** `@tailwindcss/postcss` replaces the plugin bundled with v3 and prefixes the CSS itself, so `autoprefixer` was removed.
- **Utility sweep:** the utilities renamed in v4 (`outline-hidden`, `shrink-0`, `rounded-xs`, `backdrop-blur-xs`, `placeholder:text-*`) were applied across the components; the rendering is unchanged.

### Dependency hygiene (SCRUM-147, SCRUM-148)
- **Exact pins:** `requirements.in` and `requirements-dev.in` now pin exact versions instead of floors, so an upgrade is an explicit, reviewed edit rather than something a resolution can drift into.
- **Upgrades:** postcss 8.5.33, fastapi 0.165.0, pydantic 2.14.4, and ESLint 10.15 with `@eslint/js` 10.0.1.
- Dependabot PRs #27-#35 were closed as superseded by the ticket work.

## Quality & Governance
- **Docker test stage (SCRUM-152):** `docker build --target test -t wind-map:test .` builds an Alpine image with bash and the dev requirements, so the full backend suite (136 tests, 97.75% coverage) runs inside Docker. The shipped image still has no bash and no test dependencies.
- **ruff format and pyupgrade (SCRUM-109):** Python is formatted with `ruff format` at `line-length = 120`, the `UP` rules are enabled, formatting is enforced in CI, and the formatting-only commit is listed in `.git-blame-ignore-revs`.

## Compatibility
- No API, database or UI changes: saved locations, caches and settings carry over unchanged.
- Local development now requires Node 24 and Python 3.14.
